## 1. 项目定位

星序是一站式可交互学习平台，将实验探索、课程组织和学习评价结合。学生通过改变参数、比较现象、追踪程序或完成场景任务理解知识；教师组织资源与授课过程，保留提交、反馈和评价依据。Web 体验与后端业务共同构成作品。

当前有学术教育和职业教育两类入口。学术主站围绕学科实验、编程活动与校内课程展开；职教子站围绕融媒体岗位组织采访、核实、授权和作品表达。两站已有入口跳转与联合启动，账号、课程和成绩分别管理。

本阶段面向 Web、本机毕业设计与竞赛展示。学术主站采用单校课程权限，职教动态站使用本地教学演示身份；跨校平台、正式职业身份接入、公网长期运营和真实课堂效果另有实施与验证范围。

127 项统计只包含三个原学习空间的活动身份，不包括职教课程、教师派生课程或模板版本。活动可自由探索，也可进入具体课程；来源相同不意味着共享成员、发布或完成结果。

数据分别保存在两套服务中：主站默认使用 SQLite，也有 MySQL 连接支持；职教以 PGlite 保存内容与证据关系，并通过文件记录部分会话、世界状态和作品。数据库模型、表数及代码层级见 [01 系统全局架构](01-开发者手册.md#2-系统全局架构)，实际数据位置见 [04](04-部署指南.md)。

基础教学流程的 2026-09-08 验收、后续课程版本开发与 2026-09-18 职教迁入分别记录在 [03](03-发布历史.md)。当前代码存在后续改动和待处理问题，历史测试计数不作为当前全量通过证明。

## 4. 开发与交付边界

- 学术主站的角色、发布和正式完成结果由 FastAPI 决定；职教业务由独立 Fastify 服务及世界规则处理。入口相通不表示两站已统一身份和数据。
- 课程家族、同步候选、冻结发布、检查点和作业版本历史已有实现；实验记录能力、页面接线及后续统一查询按 01、02 逐项说明。
- 模型接口与资料检索按配置和课程启用。主站助教回答不产生教师评分，职教模型建议经过规则校验；公开导览的预设访谈单独标明。
- 2026-09-17 的学术持续开发任务保持暂停；之后的独立入口改动和职教迁入按实际提交记录。本次 README 与文档更新不恢复整个研发目标。
- `main` 保存源码，`qianduan` 保存学术静态制品。源码、构建、推送和线上发布分别记录，不为普通文档维护新增产品发布号。
- 协作约定见 [AGENTS.md](../AGENTS.md)。旧材料、暂停时的本机证据和未完成验证按 [03](03-发布历史.md) 追溯，保留用户已有数据和修改。
