### 1.2 当前稳定基线

经用户确认，当前产品目标固定为：

1. 星序是可继续增加新学习星系的互动教学平台；当前学习单元只有工科试验室、代码空间和未来星系，`#planets` 是登录后的角色与任务总览，不是第四个学习星系。
2. 学生主路径是“目标 / 预测 → 操作 / 运行 → 反馈 → 修正 → 解释 / 提交”，不是被动参阅资料。只有满足版本化完成规则的服务端事实才可写成完成，目录数量和访问量都不代表教学质量。
3. 教师当前负责既有课程的班级范围、开放 / 锁定 / 隐藏、分块节奏、作业、进度、代码提交与反馈；通用低代码互动课程工厂不属于当前完成条件。
4. 管理员通过星序统一治理组织、人员、班级、课程状态和审计；可视化用于理解与受约束操作，不开放任意 SQL、原始表或无确认写库。
5. 产品借鉴综合教学平台的课程、班级和教学协作结构，但不宣称“全面替代”或“全面优于”某一成熟平台；当前差异化集中在可视化实验、代码追踪、跨学科互动和三角色对同一教学事实的闭环。
6. 学生 AI 助教、教师 AI 教学助手、AI 维护 / 管理助手属于展示后条件路线。当前无 AI provider、对话入口或写入链，运行能力继续标为 `unavailable`；恢复条件与人工确认边界见第 3.5 节。

### 1.4 已授权实施的未来星系重构契约

用户已于 2026-07-28 明确恢复开发并授权主开发依本节建立任务、恢复项目对接和调度工作组。产品代码仍须等待对应 CONTENT / FE 任务达到写入门禁，不得用本次授权绕过任务卡、视觉规格确认、版本令牌或 QA。

#### 1.4.1 当前问题

1. 当前方向页同时承担“方向目录”和“具体课程页”两种职责；以人文页为例，`语境地图 / 视角切换 / 主张审阅` 被横向标签压在同一页面内，学生无法形成清楚的方向—课程层级。
2. 当前具体课程页的标题区、目标区、活动切换和双栏学习区没有遵循工科试验室已经形成的模板化页面骨架，导致学习单元之间的课程进入方式和阅读顺序不一致。
3. 主要观察 / 操作区内容密度与布局约束不足；在用户本次观察的约 `1015×898` 视口中，柱形文本、关系节点和说明发生遮挡，视觉表现也过于简陋，已经妨碍课程判断而不只是影响装饰效果。
4. 以上问题适用于未来星系六个方向及其全部课程入口，不得只修复人文页或只用局部 CSS 遮掩。

#### 1.4.2 用户确认的目标层级

```text
未来星系主页面
└── 六个方向目录页
    └── 各方向的独立课程入口
        └── 具体课程页（目标、内容 / 实验、反馈与完成动作）
```

- 方向页只承担该方向的课程发现、课程状态和进入动作，不得继续把三门活动作为同一课程页内的二级标签。
- 每门实际课程必须使用独立路由 / 可恢复入口，并严格遵循工科试验室的模板化页面层级、主要区块和课程进入方式。
- 当前六方向 / 18 活动全部一对一保留并升级为 18 门独立课程；不得借重构合并、替换或下线其中任一门。
- 未来星系保留自身课程素材、色彩与主题表达；统一范围包括课程页面模块、导航逻辑和页脚逻辑，不直接复制工科试验室的视觉皮肤，也不得用主题差异改变信息架构、主次关系或可读性门禁。
- 主要展示与交互区必须在桌面和 `390×844` 下无文字遮挡、无根级横向溢出；图形、Canvas、Three 或动画只有在帮助观察、比较、判断和反馈时才使用。

#### 1.4.3 已冻结的实现选择

1. **课程保留**：六方向 / 18 活动全部一对一保留为独立课程。
2. **深链兼容**：由主开发选择兼容重定向。既有 `#<direction>/<activity-slug>` 深链继续可达，并规范化到新课程入口；旧方向空 hash 进入该方向目录，不再静默落到第一门课程。未知课程 slug 显示明确不可用 / 返回目录，不得静默替换为另一门课程。

## 5. 验收与风险

- 每个版本至少通过任务专项、受影响全量自动化、`git diff --check`、文档链接 / 对接门禁；用户可见路径增加真实浏览器证据。
- 展示版核心门禁是登录、角色隔离、三单元代表课、教师协同、管理治理、SQLite 对账和 9001 一键启动，不再要求生产环境证据。
- 风险：四轮 / 8 小时预算被误当作降低验收标准；18 门课程只换路由而没有教学闭环；未来星系方向页继续混用目录与课程职责并出现内容遮挡；FE-012 与 FE-017 同时写共享入口造成语义冲突；教师工作台继续暴露系统术语；管理台退化为计数面板；detached FE-012 保全树被误删、整体提交或冒充稳定实现；旧页面 / 模板被误当现行实现；诚实降级被 UI 包装成成功；课程名称或规则摘要被误宣传为已具备 AI。
- 不做：新增课程数量、装饰性 3D、任意 SQL / 表编辑、宿主执行学生源码、伪造 accepted / 完成 / AI / 生产状态、为了压测或公网部署推迟当前展示主路径。
