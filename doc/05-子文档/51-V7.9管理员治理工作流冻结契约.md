### 1.2 BE-007 候选面

UI-003 只消费以下最小候选合同：

```http
PATCH /api/courses/{course_id}/status
Content-Type: application/json

{
  "expected_status": "draft",
  "status": "published",
  "reason": "完成课程与班级发布关系复核"
}
```

- 仅全局管理员可调用；
- 请求体只允许 `expected_status / status / reason`；
- `reason` 去除首尾空格后必填，最长 1000 字符；
- same-status、stale 和非法转换均返回 409，客户端不得自动重试；
- 审计动作固定为 `course.status.patch`，记录 `before / after / reason / impact`；
- 不提供课程精确 GET、写前数字化影响预览或受影响学生数。

成功响应由课程安全投影和结构计数组成：

```json
{
  "course": {
    "id": 1,
    "school_id": 1,
    "creator_user_id": 2,
    "galaxy_key": "englab",
    "course_key": "admin-governance-demo",
    "title": "治理演示课",
    "summary": null,
    "status": "published"
  },
  "impact": {
    "attached_class_count": 1,
    "course_unit_count": 2,
    "assignment_count": 1
  }
}
```

## 2. 管理员业务信息架构

主导航固定为：

1. 治理总览
2. 组织
3. 人员
4. 班级
5. 课程
6. 审计

唯一职责：

| 领域 | 唯一职责 |
| --- | --- |
| 治理总览 | 待审关系、停用账号、归档组织、课程状态分布和最近审计；数据地图退居业务摘要之后 |
| 组织 | 学校列表、状态、说明、版本和受约束编辑 |
| 人员 | 用户角色 / 状态与待加入关系；加入审批只在此实现 |
| 班级 | 班级元数据、状态、成员摘要和分页成员 |
| 课程 | 课程发现、状态筛选、状态治理和影响回执 |
| 审计 | 精确业务审计、Request ID 对账和时间范围回读 |

既有“内容发布”进入“更多治理”；脚本资产、Host、快照、Outbox、Bug、health 和连接设置进入“高级诊断”，只在用户进入高级区后加载。首页不得继续用 `refreshAll()` 预取全部运维面板。

数据地图只解释 `用户 → 学校 → 班级 → 课程 → 作业 / 证据 → 审计` 的关系和规模；所有写入仍进入对应领域 inspector，不在关系图上直接编辑。

## 3. 课程状态语义

| 当前状态 | 允许动作 |
| --- | --- |
| `draft` | 发布为 `published`；归档为 `archived` |
| `published` | 撤回为 `draft`；归档为 `archived` |
| `archived` | 恢复为 `draft` |

- `archived → published` 禁止，必须先恢复草稿并重新复核；
- 目标等于当前状态时 UI 不发送，服务端仍以 409 fail closed；
- `published` 只代表课程具备学生访问前提，具体 Unit 的 `hidden / locked / open` 仍由发布计划决定；
- `archived` 不删除历史挂班、作业、提交、学习证据或审计；
- 恢复草稿不会自动向学生开放。

## 4. 影响确认与错误对账

BE-007 只在成功后返回结构计数，因此使用两阶段表达：

1. 写入前只显示课程身份、状态箭头、定性影响和原因，不伪造数字；
2. 写入成功后显示服务端权威计数。

计数语义：

- `attached_class_count`：当前 active 的课程—班级关联数；
- `course_unit_count`：课程下全部 Unit 数，不等于 open Unit 数；
- `assignment_count`：课程 Unit 下全部作业数，不等于可见作业数。

三项计数均不得写成“受影响学生数”“当前学习人数”或“即将开放人数”。

固定文案：

- stale：`课程状态已从「{expected}」变为「{actual}」。本次请求未重发；请核对最新状态后重新选择。`
- no-op：`课程已处于「{actual}」，没有产生写入，也不会新增审计记录。`
- invalid：`不能从「{current}」直接切换为「{target}」。已归档课程必须先恢复为草稿并重新复核。`
- unknown-result：`请求已经发出，但尚不能确认是否生效。系统不会自动重试；治理写入已锁定。请按 Request ID 回读课程与审计后再继续。`
- 403：`只有全局管理员可以调整课程状态。`
- 422：`治理原因不能为空，且只能提交目标状态、预期状态和原因。`

unknown-result 回读顺序：

1. 保存 Request ID 并锁定该课程治理写入；
2. `GET /api/courses`，按课程 ID 读取权威状态；
3. 按 `action=course.status.patch + resource_type=course + resource_id + request_id` 回读审计；
4. 课程为目标状态且审计 `after.status` 匹配时确认为成功；
5. 课程仍为预期状态且无对应审计时提示“未发现本次写入”，只允许管理员显式解锁；
6. 状态与审计不一致、读取失败或出现第三种状态时保持锁定。

任何路径都不得自动重发 PATCH。2xx 响应还必须核对课程 ID、school ID 和目标状态；不匹配时同样进入对账状态。

## 5. API 消费映射

| 场景 | API | UI 消费 |
| --- | --- | --- |
| 会话门禁 | `GET /api/users/me` | 仅 admin 解锁治理页面 |
| 业务总览 | `GET /api/admin/stats` | 待审、组织、课程和审计总量 |
| 组织 | `GET/PATCH /api/admin/schools/{id}` | 精确读取、版本化写入和回读 |
| 班级 | `GET/PATCH /api/admin/classes/{id}` | 精确读取、版本化写入和回读 |
| 人员 | `GET /api/admin/users` | 角色、状态和查询 |
| 用户治理 | `PATCH /api/admin/users/{id}` | 复用既有二次确认与未知结果写锁，不伪称具备版本 CAS 或 reason |
| 加入申请 | `GET/PATCH /api/admin/class-join-requests/{id}` | 成功后刷新申请、成员、统计和审计 |
| 班级成员 | `GET /api/classes/{id}/members/page` | 班级 inspector 的分页成员摘要 |
| 课程 | `GET /api/courses` | 本地小数据量内按状态、星系和关键词筛选；按 ID 从列表权威回读 |
| 课程状态 | BE-007 `PATCH /api/courses/{id}/status` | 单次 CAS、成功影响回执和失败对账 |
| 审计 | `GET /api/admin/audit-logs` | action、resource type / ID、Request ID 和时间范围 |

`GET /api/courses` 没有精确读取、分页或服务端状态筛选。V8 本地数据量内可复用列表，不扩张通用课程查询平台。

## 8. 双视口、键盘与动效

### 8.1 1015×898

- 保留星序 232px 外层 rail；
- 管理领域导航约 204—210px，工作区只保留两列；
- inspector 使用右侧 drawer / dialog，不再增加常驻第三列；
- 表格只允许自身横向滚动，不造成根级溢出；
- 课程状态确认和影响回执不得与固定导航重叠。

### 8.2 390×844

- 领域导航改为顶部横向滚动条并避让星序移动头部；
- 用户、班级和课程记录改为纵向摘要项；
- inspector 使用全屏原生 dialog；
- 为底部角色 dock 和 safe area 预留空间；
- `documentElement/body.scrollWidth` 必须等于 390。

交互门禁：

- 所有核心操作至少 44×44px，中心点无遮挡；
- 领域导航使用 roving tabindex，支持左右方向键、Home、End；
- dialog 打开后进入标题或首字段，Escape 关闭并返回原触发器；
- 发送中的写入不能因关闭 dialog 被表现为已取消；
- stale / invalid / success / unknown 进入可聚焦的 status / alert；
- 状态不只依赖颜色；
- `prefers-reduced-motion: reduce` 下取消平滑滚动和装饰过渡；
- 页面离开时取消读取请求、监听与焦点任务；
- 管理页不新增 Canvas、Three 或动画运行时。
