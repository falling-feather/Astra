## 1. 冻结结论

1. 地球与宇宙、工程、数据、信息、材料、人文六方向的 18 个现有活动全部一对一保留；显示名、`route_slug` 和稳定 `activity_key` 不合并、不换课、不下线。
2. canonical hash 固定为 `#frontier/<direction-slug>/<course-slug>`；方向目录为 `#frontier/<direction-slug>`，未来星系主页为 `#frontier`。
3. 既有 `#<direction-slug>` 与 `#<direction-slug>/<course-slug>` 精确兼容并用 `history.replaceState` 规范化；空方向进入方向目录，未知方向、未知课程、方向与课程错配、非法编码和多余路径段明确失败，不静默回退首课。
4. “独立课程入口”是方向目录中的可寻址课程卡，其目标直接是具体课程页；不额外创建没有内容的 `/course` 过渡页。
5. 每门课都必须形成“学习目标 → 预测 → 操作 / 观察 → 反馈 → 修正 → 解释 / 完成”闭环，并提交 CER（主张—证据—推理）或领域等价产物。访问页面、播放动画、点击公开样例、自报完成或只答对选择题都不是完成。
6. 一课只暴露一个主变量；第二变量只在重试或迁移问题中开放。相机、缩放和视角属于观察变量，不能伪装成物理变量。
7. `predicted / attempted / corrected / explained` 等事实由稳定事件记录，`completed` 只由服务端规则或可信评估派生，客户端不得直接写入。
8. 教学模型、非实尺度图形、合成数据、虚构容量和无量纲指数必须常驻标识，不能只藏在帮助弹窗或开发文档中。
9. Three 只保留给 `cosmos.orbital-scale` 的尺度与视角观察；其他课程不因视觉装饰加载 Three。减少动效模式提供等价静态或事件驱动观察，不损失教学信息。
10. 人文三课统一使用“阿波罗 11 号登月”可追溯资料包：NASA 实时空地通信记录与任务后技术复盘分别提供行动当下和事后解释视角。课程只使用带出处的短摘录或忠实摘要，不把自编练习文当史料。

## 3. 跨课程共享教学契约

1. **学习目标**：使用一句可观察、可解释的目标，同时列出本课不覆盖的现实边界。
2. **预测**：操作前提交有方向的预测和理由；只点“开始”不产生有效预测。
3. **操作 / 观察**：首轮只改变一个主变量，记录基线、改变值与至少两项证据。
4. **反馈**：指出哪项证据支持或冲突、原因是什么；不能只显示红绿、分数或“答错了”。
5. **修正**：首轮错误或证据冲突时，学习者必须修改预测、变量选择或解释并再次尝试。
6. **解释 / 完成**：提交 CER 或领域等价产物，并说明一个适用限制；代表课程再完成迁移问题。
7. **权威完成**：

   ```text
   predicted
   + attempted（至少一次；代表课至少两次对照）
   + corrected（首轮错误或证据冲突时必需）
   + explained（必须有可追溯产物）
   = completed（仅由服务端规则或可信评估派生）
   ```

## 4. 六方向 × 18 课程冻结矩阵

### 4.1 地球与宇宙

#### 4.1.1 昼夜与季节

- **身份与 owner**：`day-season`；`cosmos.day-season`；`pages/cosmos/earth-sun.js`。
- **目标 / 预测 / 主变量 / 证据**：用日期、纬度、太阳赤纬、正午高度和昼长解释季节并排除日地距离主因；先预测北京附近从春分到夏至的正午高度和昼长变化，再迁移到南半球；主变量为日期，第二轮才改变纬度；证据是赤纬、正午高度、理论昼长和昼夜分界线。
- **常见错误与反馈**：重点纠正“夏季因为更靠近太阳”“南北半球季节同步”“当前图可直接测出受光面积”。反馈分别核对预测与昼长、太阳高度两项证据，并回扣轴倾角。
- **重试与完成**：固定纬度比较两分两至，再换负纬度；提交“主张—两项证据—推理”并解释南半球季节。
- **事实核查**：**B**。轴倾角改变入射角和昼长是可靠事实；当前赤纬算法是教学近似，画面没有直接测量受光面积。依据：[NASA 季节成因](https://spaceplace.nasa.gov/seasons/en/)、[NASA Earth Facts](https://science.nasa.gov/earth/facts/)、[NOAA Solar Calculator](https://gml.noaa.gov/grad/solcalc/)。
- **保留 / 替换**：保留日期、纬度、太阳高度、昼长和昼夜图；把“受光面积”换成可观察的高度与昼长，常驻标明理想大气、近似赤纬和视太阳时。

#### 4.1.2 轨道与尺度

- **身份与 owner**：`orbital-scale`；`cosmos.orbital-scale`；`shared/js/frontier-learning.js::mountThreeOrbit`，同文件提供 Canvas 降级。
- **目标 / 预测 / 主变量 / 证据**：区分自转、绕日公转、地轴方向和观察视角，并识别模型中的非实尺度；预测地球移到轨道另一侧时哪一半球更朝向太阳，以及只旋转相机是否改变物理现象；主变量是轨道位置，相机只作观察变量；证据是太阳方向、地轴方向、昼夜分界线和相机状态。
- **常见错误与反馈**：纠正“相机变化会改变昼夜”“夸张椭圆说明距离主导季节”“屏幕尺寸代表真实尺度”。反馈明确区分物理变量与观察变量，并显示非实尺度图例。
- **重试与完成**：复位相机比较两个轨道位置，再固定位置只转相机；列出两项真实关系和两项非真实比例并解释季节关系。
- **事实核查**：**B**。约 23.4° 地轴倾角及其与轨道位置的关系可靠；现有太阳、地球、轨道大小和偏心率不是实尺度。依据：[NASA Earth Facts](https://science.nasa.gov/earth/facts/)、[NASA 季节成因](https://spaceplace.nasa.gov/seasons/en/)、[NASA Milankovitch Cycles](https://science.nasa.gov/science-research/earth-science/milankovitch-orbital-cycles-and-their-role-in-earths-climate/)。
- **保留 / 替换**：保留 Three 观察、旋转和低功耗 / Canvas 降级；常驻“非真实比例”，弱化椭圆视觉，不用画面距离解释季节。

#### 4.1.3 证据记录

- **身份与 owner**：`evidence-log`；`cosmos.evidence-log`；`pages/cosmos/earth-sun.js`。
- **目标 / 预测 / 主变量 / 证据**：用同地同日的太阳高度、方位角、归一化影长和阴影方向记录太阳视运动；预测上午、太阳正午、下午的最短影长和方向变化；主变量是观测时刻，日期与地点固定；证据是高度、方位角、阴影方位、影长 / 物高和视太阳时。
- **常见错误与反馈**：纠正“钟表 12:00 必是太阳最高时刻”“阴影与太阳同向移动”“改变杆高会改变归一化影长规律”。反馈分别指出方向和长度证据的冲突。
- **重试与完成**：记录上午、太阳正午、下午三点，补箭头和表格；提交三行证据日志与因果解释。
- **事实核查**：**C**。现 owner 只有高度和影长，不能回答阴影方向；`hour` 也被当作太阳时。主开发冻结为补充太阳方位角和反向阴影方位，并明确使用当地视太阳时。依据：[NOAA 太阳高度与方位角](https://gml.noaa.gov/grad/solcalc/azel.html)、[USNO Sun Altitude/Azimuth](https://aa.usno.navy.mil/data/AltAz)、[NWS Solar Noon 定义](https://forecast.weather.gov/glossary.php?word=s)。
- **保留 / 替换**：保留高度、影长比和时刻控制；新增方位角 / 阴影方向，明确视太阳时。若以后切换钟表时，必须同时引入经度、时区和均时差。

### 4.2 工程系统

#### 4.2.1 受力路径

- **身份与 owner**：`load-path`；`engineering.load-path`；`pages/engineering/bridge-truss.js`。
- **目标 / 预测 / 主变量 / 证据**：在理想铰接平面桁架中，用节点平衡和杆件轴力追踪载荷到支座；预测点载荷移到跨中后哪些杆件轴力绝对值增大；主变量是载荷节点，第二轮才改载荷大小；证据是支反力、拉压符号、轴力和节点平衡残差。
- **常见错误与反馈**：纠正“力像物体沿唯一道路流动”“红色必是压杆或危险”“零力杆永远无用”“真实连接都是理想铰”。反馈显示选中节点的 `ΣFx / ΣFy` 与拉压图例。
- **重试与完成**：固定载荷比较 B / C / D 三节点；用一个节点和两根杆件说明“载荷—杆件—支座”路径。
- **事实核查**：**B**。二力杆、节点载荷和节点平衡可靠，但不等同真实桥梁完整分析。依据：[Engineering Statics：Trusses](https://engineeringstatics.org/Chapter_06-trusses.html)、[Method of Joints](https://engineeringstatics.org/method-of-joints.html)、[MIT 理想桁架与实验比较](https://ocw.mit.edu/courses/1-105-solid-mechanics-laboratory-fall-2003/resources/exp4_03/)。
- **保留 / 替换**：保留矩阵求解、支反力、拉压颜色和位置预设；补符号、单位与假设，不把颜色称作真实危险等级，并列出自重、连接刚度和屈曲等未建模项。

#### 4.2.2 构件选择

- **身份与 owner**：`member-choice`；`engineering.member-choice`；`pages/engineering/bridge-truss.js`。
- **目标 / 预测 / 主变量 / 证据**：通过保留 / 移除 FB 斜杆观察特定几何的稳定性，理解三角化、机构和计数判据的局限；预测移除 FB 后方程是否仍有唯一解；主变量是 FB 状态；证据是求解秩 / 奇异状态、机构示意、`m+r` 与 `2j` 以及是否存在可解杆力。
- **常见错误与反馈**：纠正“`m+r=2j` 足以证明稳定”“任意斜杆都多余”“奇异矩阵等于所有杆力为零”“模型不可解等于真实结构立刻坍塌”。反馈分开数量检查与几何稳定检查。
- **重试与完成**：恢复 FB 验证基线，再移除并标出机构自由度；指出失稳模式并提出恢复三角化方案。
- **事实核查**：**B**。当前特定结构删除 FB 后的奇异判断可保留；一般化时计数判据只是必要而非充分条件。依据：[University of Maryland：Statically Determinate Structures](https://terpconnect.umd.edu/~austin/ence353.d/lecture-material2020/analysis-statical-determinacy-part01.pdf)、[Engineering Statics：Trusses](https://engineeringstatics.org/Chapter_06-trusses.html)。
- **保留 / 替换**：保留虚线 FB、不可校核状态和不伪造杆力；删除“有三角形就必然稳定”的泛化，反馈同时给出数量与几何判据。

#### 4.2.3 安全校核

- **身份与 owner**：`safety-check`；`engineering.safety-check`；`pages/engineering/bridge-truss.js`。
- **目标 / 预测 / 主变量 / 证据**：区分需求、名义极限、设计允许值和利用率；预测需求固定而安全系数提高时允许值与利用率的变化；主变量是安全系数，第二轮才改载荷；证据是最大轴力、名义容量、允许容量、利用率和单位。
- **常见错误与反馈**：纠正“安全系数越大结构自动变强”“130 kN 是通用规范值”“一次轴力校核证明整桥安全”。反馈逐步展示 `允许值 = 名义极限 / 安全系数` 和利用率计算。
- **重试与完成**：先手算一个案例，再只改安全系数复核；在教学模型内给出通过 / 不通过并列出两项现实遗漏。
- **事实核查**：**C**。安全系数概念可保留，但 `130 kN` 没有构件、材料、屈曲长度或规范来源。主开发冻结为“虚构教学构件的名义容量”，永久显示“不得用于工程设计”。依据：[MIT 16.20 Review of Design Considerations](https://ocw.mit.edu/courses/16-20-structural-mechanics-fall-2002/df3e56f4626796ea5ed4c913c0e5a9cb_ho1.pdf)。
- **保留 / 替换**：保留安全系数、利用率和阈值颜色；所有容量与结果都置于明确的合成教学场景。

### 4.3 数据科学

#### 4.3.1 模型拟合

- **身份与 owner**：`model-fit`；`datascience.model-fit`；`pages/data-ai/linear-regression.js`。
- **目标 / 预测 / 主变量 / 证据**：通过斜率、截距和残差比较手动模型与最小二乘线，理解单一指标不足以评价模型；先预测斜率增大时高、低 x 点残差符号的变化；主变量是斜率，重试时再调截距；证据是逐点残差、SSE / RMSE / MAE、R² 和残差模式。
- **常见错误与反馈**：纠正“穿过最多点就是最佳线”“R² 高即因果成立”“训练误差低保证泛化”“斜率没有单位”。反馈点名残差变化和系统性模式。
- **重试与完成**：把手调模型与 OLS 基线并排；选择模型并用残差和指标两类证据说明适用范围。
- **事实核查**：**B**。OLS、残差和现有指标核心正确，高 R² 不能单独证明模型合适；三套数据必须标为合成。依据：[NIST Linear Least Squares Regression](https://www.itl.nist.gov/div898/handbook/pmd/section1/pmd141.htm)、[Penn State：Simple Linear Regression](https://online.stat.psu.edu/stat501/Lesson01)、[Penn State：Residual Analysis](https://online.stat.psu.edu/stat501/Lesson04)。
- **保留 / 替换**：保留散点、拟合线、残差、OLS 和指标；补合成数据、单位和范围标签，学习率只作进阶说明。

#### 4.3.2 离群点检验

- **身份与 owner**：`outlier-test`；`datascience.outlier-test`；`pages/data-ai/linear-regression.js`。
- **目标 / 预测 / 主变量 / 证据**：区分离群点、高杠杆点和影响点，用纳入 / 暂时排除对照判断影响而非自动删除；预测标记点切换后斜率、R² 和 RMSE 的变化；主变量是标记点是否纳入；证据是两条拟合线、系数差、残差和简化影响度。
- **常见错误与反馈**：纠正“离群点一定录错”“大残差一定强影响”“高杠杆点都应删除”“R² 下降即模型无效”。反馈分别判定离群、杠杆、影响，并要求先核查来源。
- **重试与完成**：报告含点 / 不含点两次结果；说明保留、标记或排除的理由及其对结论的影响。
- **事实核查**：**B**。现演示能表现拟合线被拉动，但不足以准确教授三种概念，也缺数据来源核查。依据：[Penn State：Influential Points](https://online.stat.psu.edu/stat501/Lesson11)、[NIST：What are outliers?](https://www.itl.nist.gov/div898/handbook/prc/section1/prc16.htm)。
- **保留 / 替换**：保留含离群点样本、残差和模型偏移；删除“发现异常就删除”的暗示，补对照、影响度和来源核查。

#### 4.3.3 证据与主张

- **身份与 owner**：`evidence-claim`；`datascience.evidence-claim`；`pages/data-ai/linear-regression.js`。
- **目标 / 预测 / 主变量 / 证据**：把主张限制在样本、变量和观察范围，区分相关、因果与外推；比较“温度高导致销量高”和“样本中呈正相关”哪句更受支持；主变量是样本数据集，分析阶段锁定模型；证据是样本量与范围、散点趋势、残差、R² 和混杂因素。
- **常见错误与反馈**：纠正“相关等于因果”“高 R² 等于理论为真”“样本趋势可无限外推”“残差是唯一不确定性”。反馈分类指出因果跃迁、外推和总体泛化。
- **重试与完成**：限定人群、时段和变量后重写主张并补替代解释；提交谨慎主张、支持证据和建立因果还需要的证据。
- **事实核查**：**C**。气温—销量等硬编码数据没有现实来源，不能作为经验事实；全部改为“合成教学样本”。依据：[OpenStax：Regression Equation](https://openstax.org/books/statistics/pages/12-2-the-regression-equation)、[Penn State Regression Methods](https://online.stat.psu.edu/stat501/)。
- **保留 / 替换**：保留散点、残差与谨慎结论方向；数据名和结果常驻“合成”，反馈按因果、外推、总体化分类。

### 4.4 信息技术

#### 4.4.1 分组路由

- **身份与 owner**：`packet-route`；`infotech.packet-route`；`pages/information-technology/network-layers.js`。
- **目标 / 预测 / 主变量 / 证据**：理解跳数会增加教学模型中的处理步骤和累计传输量，但不能单凭跳数确定真实到达时间；固定链路与负载时预测跳数变化；主变量是跳数；证据是经过节点、每跳字节和模型步骤，动画时长不算实测时延。

- **事实核查**：**C**。端到端时延还包括传播、传输、处理和排队，跳数不能单独决定。依据：[RFC 6817](https://www.rfc-editor.org/rfc/rfc6817.html)、[RFC 2679](https://www.rfc-editor.org/rfc/rfc2679.html)。

#### 4.4.2 分层约定

- **身份与 owner**：`layer-contract`；`infotech.layer-contract`；`pages/information-technology/network-layers.js`。
- **目标 / 预测 / 主变量 / 证据**：把应用数据映射到 TCP 段和 IPv6 包，理解封装、分段及各层职责；预测载荷跨过教学 MSS 边界后的段数与首部开销；主变量是应用载荷长度；证据是段数、20-byte 最小 TCP 首部、40-byte IPv6 基本首部和明确标为教学参数的 1200-byte MSS。
- **常见错误与反馈**：纠正“MSS 永远 1200”“TCP 首部永远 20 字节”“应用长度等于路径累计字节”“大消息必由 IP 分片”。反馈指出标准下限与模型选择的区别。
- **重试与完成**：比较 1199 / 1200 / 1201 字节；标注一个数据包的各层字段并说明两项省略。
- **事实核查**：**B**。IPv6 基本首部 40 字节、无选项 TCP 最小首部 20 字节可靠；1200 是教学 MSS，不是通用标准。依据：[RFC 8200](https://www.rfc-editor.org/info/rfc8200/)、[RFC 9293](https://www.rfc-editor.org/rfc/rfc9293.html)。
- **保留 / 替换**：保留封装图和分段计算；常驻标明 1200 的模型身份，并说明 TCP 选项、IPv6 扩展头和链路层未计入。

#### 4.4.3 故障追踪

- **身份与 owner**：`fault-trace`；`infotech.fault-trace`；`pages/information-technology/network-layers.js`。
- **目标 / 预测 / 主变量 / 证据**：根据最后成功位置和首次失败边界提出故障假设，区分症状、定位证据和根因；预测确定性模型中指定节点故障后的停止点；主变量是故障节点；证据是最后成功跳、首次失败转移、事件日志和无故障基线。
- **常见错误与反馈**：纠正“最后可见节点必是根因”“一个红点可直接确定网络层”“所有丢包都是节点故障”“一次观察足够诊断”。反馈使用“观察事实—当前假设—下一测试”。
- **重试与完成**：关闭故障恢复基线，再逐节点注入；提交定位证据、假设和下一验证动作。
- **事实核查**：**B**。确定性注入适合练习诊断流程，但不是现实测量；现实“未收到”还需等待阈值并与超长时延、损坏等区分。依据：[RFC 7680](https://www.rfc-editor.org/rfc/rfc7680.html)。
- **保留 / 替换**：保留红色节点、停止动画和故障开关；删除“选择唯一正确网络层”的单答案模式，新增基线、日志和下一测试。

### 4.5 材料微观

#### 4.5.1 晶粒边界

- **常见错误与反馈**：纠正“所有缺陷都削弱材料”“位错就是小孔或裂纹”“位错密度增大一定降低强度”“二维路径预测真实断裂”。反馈先要求识别缺陷类型，再判断可能作用，并提供析出强化反例。

## 5. 事实与教学风险门禁

### 5.1 P0：写课程页前必须关闭

1. `cosmos.evidence-log` 补太阳方位角、阴影反向和视太阳时语义。
2. `materials.defect-path` 限定为裂纹样缺陷 / 孔洞路径；通用缺陷密度不得直接扣减强度。
3. `humanities.voice-shift` 使用同一阿波罗 11 任务的实时记录与事后复盘，保留完整出处。
4. `humanities.claim-review` 不再把仿写文当史料，也不把共现次数当证据强度。

### 5.2 P1：必须常驻模型标识

- `engineering.safety-check` 的虚构 `130 kN` 名义容量与“不得用于工程设计”。
- 三套回归数据的“合成教学样本”。
- 材料冷却、晶粒和相对强度的“合成 / 无量纲教学模型”。
- `cosmos.orbital-scale` 的非实尺度轨道。
- 地球课程的近似赤纬、当地视太阳时与理想大气。
- 网络课程的 1200-byte 教学 MSS、累计字节和确定性故障注入。

### 5.3 P2：统一措辞

- “跳数增加必然变慢”改为模型步骤或带条件的时延判断。
- `m+r=2j` 不得写成充分稳定判据。
- Fe 的 BCC / FCC 示例标明相与温度条件。
- “证据阈值”改为“同一发言段共现次数门槛”。
- “相对强度”“边界指数”“连通指数”都明确为无量纲教学指标。
