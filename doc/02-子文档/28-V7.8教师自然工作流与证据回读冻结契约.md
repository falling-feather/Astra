## 1. 冻结结论

1. 教师主路径固定为“**明确范围 → 安排课程 → 查看学生进度 → 核对学习证据 → 查看提交并反馈 → 预览学生可见状态**”。
2. 继续使用现有星序教师工作台，不另造控制后台。主导航沿用“教学总览 → 课程节奏 → 批改与学情”；证据详情和学生预览进入学生行 inspector / dialog，不增加复杂顶级路由。
3. 学校、班级和课程必须形成显式作用域。只有单一学校时可预选；存在多个班级或课程时不得静默选第一项。切换作用域立即清除旧学生、证据、提交和详情。
4. `aggregate` 只表示班级学习概况，不得代替逐学生进度矩阵或五类学习事实。
5. 学生视角是基于权威 release plan 与 progress 的只读状态预览，不是教师 impersonation；不开放教师访问真实 `#student`，不加载学生课程 runtime，也不写学习事实。
6. 教师纠正继续复用追加式 correction 原语：原事件不删除，原因必填，写入一次，随后重新读取事实与状态。界面不暴露事件 ID。
7. 浏览器练习和正式 runner 必须分栏；`runner_unavailable` 是诚实终态，不能显示 accepted、成绩或成功色。

## 3. 七分三十秒教师演示脚本

演示数据使用同一班级的一门代表课程；至少准备 open、locked、hidden 三个分块，一名学生具有五类真实学习事实、三次尝试、一个待反馈作业提交和一个 `runner_unavailable` 代码提交。任何 completed 必须由 SQLite 权威事件与规则派生。

| 时间 | 教师动作 | 屏幕必须证明 |
| --- | --- | --- |
| `0:00—0:35` | 教师登录，从 `#planets` 的真实教学事项进入 `#teacher` | 入口来自当前身份和教学范围，不显示伪 KPI |
| `0:35—1:10` | 明确选择学校、班级和课程 | 始终显示“班级 · 课程”；多范围不静默选首项 |
| `1:10—2:05` | 在课程节奏查看 open / locked / hidden，预览并发布一次调整 | 学生含义清楚；PATCH 只发一次；成功后读取最新安排 |
| `2:05—3:00` | 在批改与学情查看学生 × 分块进度并选择学生 | 显示开始、系统完成、提交、评分、最近活动和学生实际可见状态 |
| `3:00—4:15` | 打开证据详情，查看开始、预测、三次尝试、学生修订和解释 | 五类事实同源；课程专属摘要有界；完成不是访问量 |
| `4:15—5:00` | 对一条允许纠正的事实填写原因并确认 | 原记录保留；追加一条纠正；写后重新读取 |
| `5:00—5:50` | 打开待处理作业，保存评分 / 退回状态和教学反馈 | 教师与学生读取同一反馈 |
| `5:50—6:35` | 查看代码提交、授权源码和 attempt | 浏览器运行与正式判题分栏；`runner_unavailable` 不伪报 accepted |
| `6:35—7:15` | 打开学生可见状态预览 | open 可进入；locked 显示条件但无动作；hidden 连标题与稳定键都不显示 |
| `7:15—7:30` | 返回课程节奏总结安排—学习—证据—反馈 | 预览不切换身份、不运行课程、不写学习事实 |

### 5.2 `BE-007` 逐学生证据发现合同

冻结消费语义：

```text
GET /api/learning-evidence/classes/{class_id}/courses/{course_id}/events
    ?subject_user_id={student_id}
    &activity_key={optional}
    &event_type={optional}
    &limit={1..100}
    &offset={>=0}
```

最小响应：

```text
class_id, course_id, subject_user_id
items[]
  event_id                  // 只供内部纠正，不渲染
  course_unit_id
  activity_key
  event_type
  producer_type
  occurred_at
  evidence_summary          // 有界安全投影
  corrects_event_id?
  corrected_by_event_id?
total, limit, offset, next_offset
```

已集成 BE-007 的当前实现是通用安全发现层：它按 event type 读取少量精确叶，所有用户可控字符串只给结构元数据而不回显正文。它尚不知道六课的活动级枚举、范围、精度和交叉组合，因此当前通用 facts 不能直接渲染成“恢复系数”“符号表”“runner 结果”“桁架杆力”或“历史证据”。

CONTENT-004 冻结的下一层消费门禁为：

```text
(activity_key, event_schema_version, event_type, exact leaf path)
→ type / literal enum / numeric range / decimal precision / cross-leaf combination
→ fixed Chinese label
```

精确矩阵只认 27 号文档第 8 节。未知 activity、schema、event、路径、枚举、越界、非有限数或超精度数值必须省略并 `truncated=true`；每事件最多 12 个 facts。自由文本、源码、解释 / 原因 / 主张正文、revision / request hash、`source_ref`、token、未知 nested raw 及其可辨识片段一律不回显。

第一批 BE 实现只覆盖 `physics.mechanics` 与 `control-flow.loop-boundary`。力学只回读通过内部一致性校验的页面实测值；`h/H≈e²` 是教学解释目标，不是 BE 用固定理论容差重判离散积分观测的规则。循环课的**当前投影**只允许 27 号文档第 8.4 节当前 producer 表中的预测存在、浏览器预检 / 正式提交动作、成功完成浏览器运行后的公开样例 bool、浅层 runner / judge、代码修订和共享解释；运行失败事件中的 `reported_correct=false` 只验证既有 producer 形状，不显示为“公开样例未匹配”。运算符、循环体次数、输出与第一次 false 属于**未来 FE producer 增量**。BE / DATA 不得解析源码、浏览器输出、通用演示字符串或 `reported_correct` 来合成这些轨迹事实；结构化轨迹组缺失时固定显示“课程 producer 尚未提交结构化轨迹”。浏览器 public check 不得映射为正式 accepted、课程正确性或 completed。

其余四课即使 DATA 初始化器写有同名 activity 和通用五类事件，也不得按字符串相似度解释为课程事实；教师端固定显示“课程专属事实尚未接入；当前只能确认事件类型与时间。”。

权限固定为当前班级教师 / admin 正向，学生和外班教师 403；学生必须是本班有效成员，课程必须挂班。derived `completed / transferred` 可显示但不是纠正目标；是否允许纠正仍由现有 correction POST 的当前发布态与规则校验决定。

前端必须扩展共享 `AstraLearningEvidenceClient` 消费新接口，`pages/teacher/teacher.js` 不直接拼写 learning-evidence API。

## 6. 六门代表课程的教师安全摘要

教师端只消费服务端已经按 27 号文档第 8 节输出的固定 fact key；不读取原始 evidence、不在浏览器重做 allowlist，也不根据缺失字段猜测答案。

| 课程 | producer / 投影状态 | 教师只读摘要与动作 |
| --- | --- | --- |
| `physics.mechanics` | 当前有真实交互 producer；第一批 BE 切片 | 显示预测枚举、理由长度、两次固定 `e/H/h/h÷H`、结构化修正和理想条件确认；教师比较两次受控组合，不读取理由或解释正文，也不以理想 e² 固定容差否定页面实测值 |
| `mathematics.derivative-application` | 待 FE / DATA producer；当前固定降级 | 将来显示切点、斜率符号、左右符号表、临界点类型和“驻点不足”结论 ID；当前只显示事件类型与时间 |
| `control-flow.loop-boundary` | 当前 producer 仅有浅层动作；第一批 BE 当前投影；详细轨迹待 FE producer | 当前只显示预测已记录、浏览器预检 / 正式提交动作、成功运行后的公开样例 bool、浅层 runner / judge、代码修订和结构化解释；运行失败只显示“未形成公开样例结论”，不把 producer 的 `false` 展示为未匹配。不得推断运算符、次数、输出或第一次 false；accepted / runner / completed 结论须在代码详情读取 code-submissions / attempt |
| `debugging-testing.minimal-case` | 待课程重写及 FE / DATA producer；当前固定降级 | 将来按四个固定阶段显示 case ID、规模、expected / actual、谓词和失败签名；永不显示源码或 revision hash |
| `engineering.load-path` | 当前有 solver、无证据 producer；当前固定降级 | 将来显示固定 60 kN 的 B / C / D、Ay / Ey、GH / CD、二维残差和理想模型确认；数值只代表本页理想模型 |
| `humanities.claim-review` | 待批准 corpus 与 FE / DATA producer；当前固定降级 | 将来只显示冻结 claim / source / context / evidence / revision / next-question ID 的中文标签；不显示原主张、修订主张或问题正文 |

`evidence_summary.truncated=true` 只表示至少有字段因安全或合同门禁被省略，不表示学生答错。facts 为空时仍可显示外层 `event_type / occurred_at / corrected_by_event_id`，但不得生成课程专属结论。

| 状态 | 冻结文案与行为 |

| 范围 loading | `正在读取你可管理的班级和课程…`；不显示旧范围 |

| 无班级 | `当前账号没有可管理班级。请联系管理员分配教学范围。` |
| 无课程 | `这个班级尚未挂接课程。请先到“组织与课程”完成挂接。` |
| 无学生 | `当前班级没有有效学生，暂时无法查看进度。` |
| 无证据 | `尚无学习证据。学生完成预测或尝试后会显示在这里；浏览页面本身不计完成。` |
| 课程事实未接入 | `课程专属事实尚未接入；当前只能确认事件类型与时间。` |
| 循环结构化轨迹未接入 | `课程 producer 尚未提交结构化轨迹；当前不会从源码、浏览器输出或公开样例推断运算符、次数与结果。` |
| 有限事实被截断 | `部分事实未通过有限事实校验，已安全省略；请勿据此判断答案正确性。` |
| 403 | `你无权查看这个班级或课程。系统没有显示其他教学范围的数据。`；清空内容 |
| release 409 | `课程安排已被其他操作更新。已读取最新状态；你的草稿没有自动重发，请核对后再次确认。` |
| correction 409 | `这条记录已被纠正，或课程状态已经变化。已刷新最新证据，没有重复写入。` |
| 写入结果不明 | `尚不能确认本次写入结果。系统不会自动重试；请先读取最新状态。` |
| open | `开放：学生现在可以进入。` |
| locked | `锁定：学生可以看到，但当前不能进入。`；无进入动作 |
| hidden | `隐藏：学生端不会显示这个分块及其名称。` |
| locked / hidden 纠正 | 历史仍可查看，当前不能新增纠正；分别诚实处理 409 / 403 |
| `runner_unavailable` | `正式判题未启用（runner_unavailable）。提交已保存；浏览器预检不等同正式通过。` |
| `browser_runtime_error` | `浏览器练习运行失败（browser_runtime_error）。请检查代码或输入；这不是正式判题结果。` |
| 离线 | `当前离线，不能安全发布安排、反馈或纠正记录。恢复连接后请重新读取最新状态。` |

纠正确认文案：

> 原记录不会被删除。本次纠正将作为新记录保留，系统会依据课程完成条件重新核对状态。

成功文案：

> 纠正已记录，原记录仍保留；学习状态已按最新证据重新核对。

不得承诺学生“已掌握”。

## 8. 响应式、键盘与生命周期

1. Tab 顺序固定为星序导航 → 学校 → 班级 → 课程 → 当前视图导航 → 主内容 → 主动作。
2. scope 使用原生 `select`；多项包含“请选择…”，不得在焦点到达时自动选中。
3. 视图导航使用 roving tabindex；左右方向键切换，Enter / Space 激活。
4. 桌面学生进度使用语义表格；390×844 改为学生列表 + 分块 disclosure，不强行缩窄宽矩阵。

## 10. 不进入范围

- 不建设通用课程创作器、任意题型或低代码工作室。
- 不做教师 impersonation，不新增学生预览后端 API，不复制学生 runtime。
- 不做排课、催交通知、复杂逾期、跨校学期分析、家长端或 AI 自动反馈。
- 不把访问、点击、浏览器 pass、aggregate 或旧 knowledge 判为掌握。
- 不允许教师 UPDATE / DELETE 学习事实，也不纠正 derived completed / transferred。
- 不在通用证据区显示完整源码、完整开放文本、原始 JSON 或内部事件标识。
- 不新增真实 runner；不进入管理员治理、MySQL、公网、TLS、压力测试、安全平台或生产发布。
- 不由 BE / DATA 解析源码、浏览器输出、公开样例或通用演示字符串来合成循环轨迹；不把 public check 冒充正式 accepted、课程正确性或 completed。
- 本轮先为力学与循环提供课程专属有限摘要；其余四门代表课保留已冻结合同与固定降级，不能用 DATA 通用样例或前端本地映射提前伪装支持。六课之外只显示不带学科结论的有界通用元数据。
