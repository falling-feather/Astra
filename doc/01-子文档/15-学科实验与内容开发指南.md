### 6.6 代码空间子站（codespace 星系，V7.5.7）

代码空间是星序顶层下的第二个星系，独立部署在 `/codevis/` 目录，由主站 `pages/planets/` 通过 `externalUrl` 跳转进入。

| 模块 | 文件 | 作用 |
| --- | --- | --- |
| 子站入口 | `codevis/index.html` | 独立 SPA，独立 `<title>` 与 manifest |
| 路由 | `codevis/shared/js/router.js` | `CvRouter`（hash 路由，命名空间隔离） |
| 启动 | `codevis/shared/js/main.js` | 注册课程目录、子课、挑战与兼容追踪路由 |
| 课程清单与状态 | `codevis/shared/js/course-manifest.js` | 6 组/18 活动稳定键，以及 BE-004 same-origin 发布状态 adapter |
| 学生上下文 | `codevis/shared/js/student-context.js` | Cookie Session、本人班级 / 课程 / 单元映射及共享证据 scope；单班级自动选定，多班级失败关闭 |
| 正式提交 | `codevis/shared/js/submission-adapter.js` | 按稳定活动解析题目、提交源码并读取本人权威提交/判题状态 |
| 课程目录 / 子课 | `codevis/pages/course-catalog/` | 扫描目录、单一目标简报与发布状态呈现 |
| 可执行挑战 | `codevis/pages/course-challenge/` | 预测、运行、追踪、修正、公开预检与权威正式提交；`control-flow.loop-boundary` 发送最小 predicted / attempted / corrected 事实 |
| Runtime 抽象层 | `codevis/shared/js/runtime.js` | 统一 `markPtr` / `markSwap` / `markArray` / `snap` 标记协议 |
| 运行时加载 | `codevis/shared/js/runtime-loader.js` | 仅按需加载 `vendor/manifest.json` 审计过的同源固定资产 |
| JS / Python | `codevis/shared/js/runtimes/runtime-js.js`、`runtime-py.js` | 在浏览器解释器中执行学习样例 |
| C/C++ | `codevis/shared/js/runtimes/runtime-cpp.js` | 独立 Worker 执行，主线程 4.2 秒硬终止并支持取消 |
| 兼容代码追踪 | `codevis/pages/code-trace/` | 保留时间轴、步进与数据结构面板，不再作为默认首页 |

**关键约束**：
- CSS 类名命名空间一律 `cv-` 前缀，全局变量一律 `Cv*` 前缀，避免与主站冲突
- 子站不依赖主站 `shared/`；自身令牌位于 `codevis/shared/css/tokens.css`。页脚的信息列、对齐与移动折叠沿用工科试验室骨架，但保留代码空间文案与视觉语言。
- 主站入口统一指向 `codevis/index.html#catalog`；`#lesson?activity=...`/`#challenge?activity=...` 使用稳定活动键支持刷新恢复，内存 Session 只镜像当前选择，路由参数不能当权限来源。
- `CvStudentContext` 只从 same-origin Cookie Session 和本人课程建立明确 `course_ids + class_id`；单班级可自动选定，多班级无显式选择、缺失映射、401 或异常均失败关闭。上下文只存内存，认证丢失时清空 adapter 和课程 DOM。
- `CvSubmissionAdapter` 只在 effective open 且存在权威题目时启用正式提交；公开预检不写 accepted。提交幂等冲突、课程撤回和 runner 不可用必须显示真实状态，不得用浏览器结果覆盖服务端记录。
- 代码挑战只为 `control-flow.loop-boundary` 接入首批共享证据：预测先于首次运行，运行 / 公开检查 / 正式提交记录允许的操作枚举，源码发生变化后才记录修正；事件 evidence 不包含源码、完整答案或自由文本。401 必须等待共享队列清理成功后再跳回目录；清理失败时进入本页不可逆的 `authority_clear_failed` 终态，清空 scope、隐藏并禁用选班器，`selectClass`、路由解析和活动入口继续失败关闭。只有新页面在 authority 准备成功后才能恢复，持久 marker / epoch 会阻止后续入口误配旧身份。
- 第三方运行时固定在 `codevis/vendor/`，许可证和哈希清单必须随资产更新；禁止改成分支 URL 或 CDN。学生页面不得显示运行时实现说明。

### 6.7 未来星系课程（frontier 星系，V7.5.7）

未来星系继续位于主站 SPA，但 V7.5.5 已把 `index.html` 中的六方向长页收缩为 7 个最小运行挂载点；课程 DOM 只由当前路由在进入时创建。V7.5.8 又从静态入口移除 `frontier-learning.js`，改由 page registry/Router 只在未来星系目录或子课路由加载；非未来角色页不再解析该运行时。

| 模块 | 文件 | 作用 |
| --- | --- | --- |
| 清单与状态 | `pages/frontier/frontier-manifest.js` | `future-galaxy`、6 个课程键、18 个活动键、route slug 与 BE-004 状态适配 |
| 发布上下文 | `shared/js/frontier-publication-context.js` | Router 前消费 Cookie Session、本人班级/课程并为直达目录或子课配置 adapter |
| 课程壳 | `pages/frontier/frontier.css` | 总览、子课、观察舞台、判断区和工科同构页脚的开放式深空布局 |
| 生命周期 | `shared/js/frontier-learning.js` | 目录/子课渲染、Canvas owner、Three 动态导入、判断反馈和统一 destroy |
| 2D owner | `pages/cosmos/earth-sun.js` 等六方向既有交互文件 | 仅在当前课程需要时创建 Canvas、监听器和观察反馈 |
| 3D 代表课 | `#cosmos/orbital-scale` | 用位置、方位和太阳点光源解释昼夜；不是非教学装饰场景 |
| 本地 Three | `shared/vendor/three-r185/` | 锁定 `three@0.185.1` 的 module/core、MIT 许可、integrity 与 SHA-256 来源清单 |
| 生成主视觉 | `UI/future-galaxy/orbit-observatory.webp` | 1600×900 课程目录主视觉；不承载文字、按钮或状态 |

**关键约束**：
- `#frontier` 当前是占满可用动态视口、禁止页面纵向滚动的六节点星图；节点保持普通 DOM 链接与键盘焦点，低频星光在 `prefers-reduced-motion` 下静止。它只负责发现和直达当前 open 方向，方向 / 子课页面仍使用正常文档流。该增量不改变 FE-017 规划中的 canonical 四层路由，也不把现行六方向 owner 写成 18 门独立课程页已经完成。
- 六方向 hash 使用稳定 `route_slug`，`activity_key` 只作前后端课程身份，不直接泄漏到 hash 或替代授权。
- `FutureGalaxyPublicationContext` 为 `FrontierCourseManifest.configureHttp()` 提供明确课程 ID 映射、`class_id` 和 same-origin fetch；BE-004 缺失活动按 hidden，任一响应失败则整份目录 unavailable。直达子课同样受控：hidden 使用无标题通用不可用页，locked 显示教师节奏说明但不挂载互动 owner。
- 普通课程优先使用各自 Canvas owner；只有“轨道与尺度”动态导入 Three。减少动效、低性能或 WebGL 不可用时不得请求/依赖 Three，Canvas 降级仍须支持观察、调参和判断。
- V7.5.8 的两张未来星系首屏背景固定为 WebP，共 136,676 字节，不进入全局 APP_SHELL；本机预览必须返回精确 `image/webp`。V7.9.68 只对 `#frontier` 总览改为单视口内部裁剪；方向 / 子课继续正常纵向文档流。轨道太阳/光源位于椭圆焦点，网络 Canvas 响应减少动效并限制设备像素比。
- 离页先 abort，再取消 RAF、断开 ResizeObserver/事件、关闭 bitmap，并释放 Three geometry、material、texture、render list、renderer 与 WebGL context；异步 import 完成后发现路由已离开时必须移除临时 canvas。
- 页脚沿用工科试验室的品牌/课程/关于三列和版权行关系，保持未来星系文案与左对齐；学生页面不显示 Three、渲染器或降级实现说明。

## 11. 实验模块开发指南

### 11.1 新增实验步骤

V8.2 `EXT-01` 的权威模板位于 `tools/templates/new-experiment/`。模板不会进入生产目录、路由或缓存；只有开发者复制并完成登记后才形成新实验，因此不会为了统一结构触碰旧实验。

1. **先完成身份去重**：确认 `subject.id`、`#subject/id`、标题和 owner 均未出现在 `shared/js/config.js`、`shared/js/experiment-registry.js`、`index.html` 与学习活动清单中。发现与既有活动相似时停止选题并记录到二号文档，不能换一个名字继续制作。
2. **复制六份模板**：把 manifest、module、JS、CSS 与 `preview-record.json.tpl` 复制到新目录 `pages/<subject>/<experiment-id>/` 并去掉后缀；`model-notes.md.tpl` 不放进 `pages/`，而是参考 `model-notes.example.md` 填充后追加到本页对应实验说明章节。模型、预览、视觉和浏览器旅程 contract 是质量规则，不复制进实验目录。

| 模板 | 复制后的职责 |
| --- | --- |
| `manifest.json.tpl` | 冻结 key、路由、owner、版本化 module/脚本/样式、预览和模型文档入口；只作注册前开发清单，不由运行时自动消费，生产接线完成后退役 |
| `module.html.tpl` | 提供首屏可操作的独立模块；候选阶段供隔离浏览器运行器挂载，通过后再放入 `index.html` 对应新位置 |
| `index.js.tpl` | 提供初始化、参数变化、重置、暂停、DPR、ResizeObserver、rAF、只读 `debugSnapshot()` 和完整 destroy 骨架 |
| `styles.css.tpl` | 提供只属于新实验的响应式样式；所有选择器必须同时包含 page、module 与 namespace |
| `model-notes.md.tpl` | 形成 11 节模型记录，覆盖结论边界、变量/单位、公式、假设/限制、数值方法、画面映射、两类样例、误差、实现对应、依据与复核 |
| `preview-record.json.tpl` | 记录封面身份、替代文本、尺寸/字节/哈希、来源、权利、源文件、静止降级和内容边界；复制为 `preview.json` |

3. **一次性替换全部占位符**：占位符不得进入生产代码。owner 使用稳定 PascalCase，其他身份使用小写 kebab-case。

| 占位符 | 示例 | 约束 |
| --- | --- | --- |
| `__SUBJECT__` | `physics` | 必须是当前真实学科 page |
| `__EXPERIMENT_ID__` | `wave-interference-lab` | 与目录 id 和 hash 尾段完全一致 |
| `__EXPERIMENT_TITLE__` | `波的叠加与干涉` | 面向用户的短标题 |
| `__OWNER__` | `WaveInterferenceLab` | 同时形成 `window.<Owner>` 与 `init<Owner>` |
| `__NAMESPACE__` | `wave-interference-lab` | 只用于 `.astra-exp--<namespace>` 样式作用域 |
| `__ASSET_VERSION__` | 已分配的小版本资源代际 | 禁止写 `latest`、时间戳猜测或复用旧实验代际 |
| `__PARAMETER_LABEL__` | `位移` | 实验首屏唯一主参数的短标签 |
| `__PARAMETER_UNIT__` | `m` | 与模型变量一致的可见单位，不写实现说明 |
| `__PRIMARY_LEGEND__` | `运动对象` | 舞台主视觉标记的短名称 |
| `__SECONDARY_LEGEND__` | `参考位置` | 舞台辅助标记的短名称 |
| `__ACCENT_TOKEN__` | `--accent-purple` | 使用当前学科已有主题 token，不新建全局颜色 |
| `__ACCENT_RGB__` | `139, 111, 192` | 与主题色一致的 RGB 通道，仅供模板透明色使用 |
| `__PREVIEW_ALT__` | `蓝色波峰随相位差改变并在中央形成相长干涉` | 描述画面和可观察变化，不能只写标题、图片、封面或截图 |

模型文档锚点不再单独填写。manifest 和说明模板都从实验 id 自动生成 `model-<experiment-id>`，例如 `model-wave-interference-lab`；不得手工改成另一份命名，避免 manifest 链接与实际章节失配。

4. **准备接线清单但暂不写入生产表面**：先在 manifest、module 与评审记录中确认未来要追加的目录条目、HTML、样式链接和 runtime 定义；浏览器旅程通过前，不修改 `shared/js/config.js`、`index.html`、`shared/js/experiment-registry.js` 或 Service Worker。下方代码只作为待接线形状，不代表此时已经注册。

```javascript
define(
    'subject',
    'new-experiment-id',
    'pages/subject/new-experiment-id/index.js?v=已分配资源代际',
    'initNewExperimentOwner',
    validatedMethod('NewExperimentOwner', () => NewExperimentOwner)
)
```

只有 `destroy()` 已真实取消 rAF、AbortController、ResizeObserver、事件、定时器和独占图形资源，并通过隔离旅程的离开/重入测试后，才能使用 `validatedMethod`。不得把新实验先登记成 `missing` 后直接发布，也不得为了复用模板改变旧 registry 项。

5. **补齐并复核模型说明**：把渲染后的 `model-notes.md.tpl` 追加到本页，参考完整样例填写 11 节。至少提供自变量、因变量和 SI 单位，一个公式/递推关系/算法不变量，适用条件、简化假设和已知限制，典型值与边界值两组输入输出，误差预算、实现位置及两条被正文实际引用的结构化依据。复核状态只有在五项复核全部勾选后才能写为“已复核”。该说明用于开发、论文和答辩，不复制成实验首屏长文。
6. **制作并登记预览封面**：从新实验自己的舞台截取或原创绘制 1600×900 画面，导出静态 `preview.webp`，不得从旧活动抓图或搬运素材。先执行 `--inspect` 读取实际尺寸、字节和哈希，再填入 `preview.json`；可选短循环另存 `preview-motion.webp`，但任何减少动态效果场景都使用静态 poster。
7. **先做隔离浏览器旅程**：保持 `registration_state: candidate-unregistered`，运行器从 manifest 读取版本化 `module.html`、JS 和 CSS，在本机临时页依次执行桌面、手机和减少动态效果流程，并把 JSON 报告及截图写到被 Git 忽略的证据目录。

```powershell
node tools/browser/check-new-experiment-journey.cjs --manifest pages/<subject>/<experiment-id>/manifest.json --out test-screenshots/new-experiment/<activity-key>
node tools/browser/check-new-experiment-journey.cjs --validate-report test-screenshots/new-experiment/<activity-key>/browser-journey-report.json --manifest pages/<subject>/<experiment-id>/manifest.json
```

正常报告必须同时包含 `desktop 1440×900`、`mobile 390×844`、`reduced-motion 1440×900`，三组的 `enter/first-draw/operate/mode-control/reset/horizontal-overflow/leave-release/re-enter/console-clean` 均为 true；手机还必须有 `drawer-toggle/touch-targets`。报告是评审附件，不是生产资源，不得加入 Service Worker。

8. **需要时显式打开开发调试面板**：调试面板不是必经的学生旅程，也不是竞赛画面。只有排查模型、步长、帧率、Canvas 尺寸或释放问题时才增加 `--debug`；需要人工停留检查时再配合 `--headed --debug-hold <毫秒>`。不写 `--debug` 时，候选页不会请求调试脚本、建立调试全局对象、DOM 或采样定时器。

```powershell
node tools/browser/check-new-experiment-journey.cjs --manifest pages/<subject>/<experiment-id>/manifest.json --debug --headed --debug-hold 300000 --out test-screenshots/new-experiment/<activity-key>-debug
```

调试模式显示运行状态、模型变量、模拟步长、帧率、活跃 rAF、ResizeObserver、控制作用域和画布尺寸。手机面板固定在视口底部并内部滚动；关闭或离开候选必须清除面板节点与 250ms 采样定时器。不得把 `new-experiment-debug-panel.js`、专用脚本路由或面板 DOM 复制进实验目录、`index.html`、注册表或 Service Worker。

9. **隔离验收通过后完成接线并回归**：此时才在 `shared/js/config.js` 追加唯一目录条目，在 `index.html` 追加 module HTML 与新样式，在 `shared/js/experiment-registry.js` 追加唯一 runtime 定义。生产接线前后各执行旧活动保护检查，确认差异只有新增身份；模板、候选注册和全项目合同分别验证新结构、接线冲突与整体回归。

```powershell
node tools/quality/check-protected-activity-changes.cjs
node tools/tests/new-experiment-template-contract.cjs
node tools/tests/new-experiment-visual-primitives-contract.cjs
node tools/quality/check-new-experiment-model-document.cjs --manifest pages/<subject>/<experiment-id>/manifest.json
node tools/quality/check-new-experiment-preview.cjs --inspect pages/<subject>/<experiment-id>/preview.webp
node tools/quality/check-new-experiment-preview.cjs --manifest pages/<subject>/<experiment-id>/manifest.json
node tools/browser/check-new-experiment-journey.cjs --manifest pages/<subject>/<experiment-id>/manifest.json --out test-screenshots/new-experiment/<activity-key>
node tools/tests/new-experiment-debug-panel-contract.cjs
node tools/quality/check-new-experiment-registration.cjs --manifest pages/<subject>/<experiment-id>/manifest.json
node tools/quality/check-protected-activity-changes.cjs
npm test
```

旧活动检查正常输出为 `124 protected activities PASS`，并把合法新增计入 `unprotected addition(s) ignored`；这表示新增没有改写旧活动，不表示新增实验本身已经通过质量验收。注册专项会同时拒绝身份、module/脚本/样式、预览、模型、owner 和 cleanup 冲突，但不会写入 `CONFIG`、registry 或 `index.html`。隔离旅程证明候选本体可挂载和释放；完成生产接线后仍要做真实 hash 进入、A→B、B→画廊、画廊→A、刷新、公共浮层、焦点和 console 的保护性集成 smoke。
10. **生产接线后退役候选 manifest**：当目录条目、DOM、runtime、真实路由和生产浏览器 smoke 全部通过后，删除新实验目录中的 `manifest.json`，再运行 `node tools/quality/check-new-experiment-registration.cjs`，结果必须为 `no candidate manifest found; protected baseline unchanged`。这是候选状态结束，不是删除科学证据：可读 `module.html`、`preview.json`、poster、15 号模型记录、03 发布记录和 Git 历史全部保留。若 manifest 继续留在生产树，发现器会把已注册身份再次作为待注册候选并以冲突失败关闭。
11. **按登记点回退**：若新实验未达到验收要求，删除它自己的目录条目、runtime 定义、HTML 挂载、样式链接和预览资源即可使新路由不可达；保留 Git 历史和失败报告供追溯。不得用回退新实验为理由修改或删除旧实验。
12. **受保护差异先停手并登记**：若旧活动检查输出 issue，不得自行更新 `protected-activities-v822.json`。先把学习空间、activity key、精确文件、知识证据、可见影响和回退方案写入二号文档，取得项目负责人批准；批准后才可把工具输出的精确 64 位 signature 与任务号、批准人、日期、理由、`one_time: true` 写入 `protected-activity-exceptions.json`。该例外只允许完全相同的 before/after 差异，任务结束后仍应由后续明确版本决定是否重建基线。

#### 11.1.1 V8.2.3 新实验视觉基础件

视觉基础件只适用于从模板复制的新增实验，不要求旧实验迁移。舞台区固定包含运行状态、当前可观察量和两项图例；控制区固定包含一个带单位主参数、播放/暂停、重置和一句短状态反馈。这里的“一套基础件”是交互与状态契约，不是课程壳：实验首屏不得增加学习目标、章节导语、长篇原理、证据工作台或实现技术说明。

- `running` 表示连续模拟正在推进；`paused` 表示画面保持且参数仍可调；`reduced-motion` 停止连续 rAF，但参数变化仍必须产生静态可观察结果。
- 桌面使用舞台/控制双栏，834×1112 平板允许收窄双栏，760px 以下按舞台—原生 `<details>` 控制抽屉顺序单列，480px 以下动作按钮单列。
- 按钮、滑杆和移动 summary 的最小可触达高度为 44px；键盘焦点必须可见，关闭抽屉不能破坏再次展开后的控件状态。
- 所有选择器必须以 `#page-<subject> [data-module="<id>"] .astra-exp--<namespace>` 开头；学科差异只通过 `__ACCENT_TOKEN__` 和 `__ACCENT_RGB__` 注入，不覆盖全局或旧实验 CSS。
- 舞台使用有上、下界的 `clamp()` 高度；Canvas 从父级 `clientWidth/clientHeight` 读取内容盒尺寸，零尺寸时直接返回。禁止把含边框的父级 rect 高度写回子 Canvas，避免 ResizeObserver 每轮把父级再撑高。
- 浏览器最低验收为 1440×900、834×1112、390×844 和 `prefers-reduced-motion: reduce`；每组都检查主操作、参数/读数同步、暂停或静态状态、根级横向溢出和 console warning/error。

#### 11.1.2 V8.2.4 模型说明与科学复核

模型记录是新实验进入目录前的科学证据，不是实验页面组件。`model-document.contract.json` 把“写过说明”转换为可验证条件，`model-notes.example.md` 展示一份合格记录的完整粒度；开发者不能删除栏目来迁就尚未想清楚的模型。

- **身份层**：显式 `<a id="model-<experiment-id>"></a>`、三级标题、实验身份和 manifest 必须一一对应；说明路径只允许指向仓库 `doc/` 内 Markdown。
- **变量层**：变量表至少含一个自变量和一个因变量，每行写明 SI 单位或无量纲 `1`、范围、默认值与显示精度；画面单位不得替代模型单位。
- **关系层**：至少写一个公式、递推关系或算法不变量，并说明符号与量纲/类型；解析模型也要写明为何不需要数值积分，离散模型要写步长、容差或停止条件。
- **边界层**：适用条件、简化假设和已知限制缺一不可；“禁止外推”要说明评委和学生不能从画面推出什么。
- **证据层**：至少一组典型值和一组边界值，每组包含输入、期望输出、容差/判定规则、推导/来源和实测结果；至少两条参考依据使用 `[R1]`、`[R2]` 编号并在正文真实引用。
- **实现层**：模型项要映射到精确文件/函数和验证入口，误差预算说明估计范围、可见影响和处理方式；不得用“教学近似”四个字代替误差分析。
- **发布层**：复核状态必须为“已复核”，日期使用 `YYYY-MM-DD`，五项复核全部勾选；`[待填写]`、`TODO`、`TBD`、课程导语和课前/课后任务都会使检查失败。

#### 11.1.3 V8.2.5 预览素材与来源记录

预览素材的职责是让目录卡片在一眼内展示“这个实验会发生什么”，不是给卡片增加装饰背景。当前 V8.2.5 只建立新增实验流程，不为既有活动批量补图。

- **静态必需**：`preview.webp` 固定 1600×900、非动画、1—120 KiB。优先截取一次有意义的操作结果，不使用初始空画布、欢迎页、说明面板或整页浏览器截图。
- **短循环可选**：只有静态画面无法表达关键变化时才增加 960×540 animated WebP；目标 1.5—5 秒、最多 60 帧、768 KiB。当前版本未提交正式动图样例，不能把可选能力写成已生产内容。
- **替代文本**：12—120 个字符，包含对象、变化和观察结果；禁止只写实验标题或“图片/封面/截图/preview”。同一文本同时进入 manifest 与来源记录。
- **来源记录**：写明 `browser-capture/original-render/manual-illustration/generated-original`、路由、舞台选择器、1600×900 视口、责任人、日期、权利状态和实际参与画面的新实验源文件。
- **完整性**：先用 `--inspect` 读取真实宽高、字节、SHA-256、动画、帧数和时长，再写记录；不得手填估计值。文件、记录和 manifest 任一不一致都会失败。
- **内容边界**：`shows_interaction_result=true`、`decorative_only=false`、`old_activity_source=false`、`embedded_title=false`。这四项不是随意勾选；复核者要根据实际画面确认。
- **静止降级**：manifest 与记录均写 `reduced_motion: poster`。目录以后即使支持短循环，也必须在减少动态效果时只显示静态封面。

#### 11.1.4 V8.2.6 隔离浏览器旅程与证据

`browser-journey.contract.json` 固定三组环境和验收语义；`check-new-experiment-journey.cjs` 负责产生实际证据。它只接受 `candidate-unregistered` 候选，以免开发者先把半成品挂进生产页面再补测试。

- **候选加载**：manifest 必须显式登记版本化 module、JS 与 CSS，三者均位于 `pages/<subject>/<id>/`。运行器启动 loopback 临时页并直接挂载 module，不读取或写入生产目录。

#### 1. 现象与结论边界

- **主要现象**：两套参数相同、只在第二摆初始角上存在微小差异的双摆同步释放后，末端轨迹和相空间轨迹会从近似重合逐步分离。
- **允许结论**：在给定的理想双摆模型和数值精度内，非线性系统的相近初始状态可以演化出显著不同的有限时轨迹；初值差越大并不保证任意时刻的末端距离都单调增大。
- **禁止外推**：本实验不测定正式李雅普诺夫指数，不建立分岔图，也不能据画面预测真实装置的长期精确轨迹、证明所有双摆状态都处于混沌区或把某一时刻的分离距离解释为“混沌强度”。

#### 3. 核心关系与符号约定

两套轨迹使用同一组质量、杆长、重力、阻尼和积分器，唯一初始差异为：

$$
\theta_{2,B}(0)=\theta_{2,A}(0)+\Delta\theta_2(0),\qquad
\Delta\theta_2(0)=\left(0.05+0.0195p\right)\frac{\pi}{180}.
$$

对任一轨迹，摆球位置和对比读数为：

$$
\begin{aligned}
x_1&=l_1\sin\theta_1, & y_1&=l_1\cos\theta_1,\\
x_2&=x_1+l_2\sin\theta_2, & y_2&=y_1+l_2\cos\theta_2,\\
d(t)&=\sqrt{\left(x_{2,A}-x_{2,B}\right)^2+\left(y_{2,A}-y_{2,B}\right)^2}.
\end{aligned}
$$

无阻尼时用机械能的相对漂移复核积分稳定性：

$$
E=\frac12(m_1+m_2)l_1^2\omega_1^2+\frac12m_2l_2^2\omega_2^2
+m_2l_1l_2\omega_1\omega_2\cos(\theta_1-\theta_2)
-(m_1+m_2)gl_1\cos\theta_1-m_2gl_2\cos\theta_2.
$$

- **符号约定**：竖直向下为角度零位，向右偏转为正；`A`、`B` 表示两套独立状态；`m₁=m₂=1 kg`、`l₁=l₂=1 m`、`g=9.81 m·s⁻²`；实现中的 `θ₁,ω₁,θ₂,ω₂` 按此顺序组成状态向量。
- **量纲/类型检查**：位置式各项量纲为 `m`，`d(t)` 为 `m`；能量式每项均为 `kg·m²·s⁻² = J`；`p` 为无量纲，乘 `π/180` 后初始角差以弧度进入三角函数。
- **依据引用**：双摆的拉格朗日建模与能量关系依据 [R1]；四阶 Runge–Kutta 的离散推进形式和阶数依据 [R2]。

| `R_s` | 因变量 | 两个相邻峰以基线峰宽计算的分离度 | `1` | 无量纲 | 默认相邻峰为 `2.451`、`1.847` | 最小值 `1.847` | `0.01` |
| `t` | 状态变量 | 当前检测扫描的模型时间 | `s` | `min` | 每轮 `[0,t_axis)` | `0 min` | `0.1 min` |

#### 3. 核心关系与符号约定

主参数先映射为等间隔保留因子，流量再决定死时间和总保留时间：

$$
\begin{aligned}
\Delta k&=0.25+0.0075p,\\
(k_A,k_B,k_C)&=(0.6,\ 0.6+\Delta k,\ 0.6+2\Delta k),\\
t_M&=\frac{V_M}{F},\\
t_{R,i}&=t_M(1+k_i),\qquad \frac{v_i}{u}=\frac{1}{1+k_i}.
\end{aligned}
$$

页面固定教学塔板数 `N=900`，以对称高斯峰绘制检测信号，并按基线峰宽计算相邻峰分离度：

$$
N=\left(\frac{t_{R,i}}{\sigma_i}\right)^2
=16\left(\frac{t_{R,i}}{w_{b,i}}\right)^2,
\qquad
S_i(t)=\exp\!\left[-\frac12\left(\frac{t-t_{R,i}}{\sigma_i}\right)^2\right],
$$

$$
R_{s,i,i+1}=\frac{2\left(t_{R,i+1}-t_{R,i}\right)}{w_{b,i}+w_{b,i+1}}.
$$

- **符号约定**：`A→B→C` 按保留因子从小到大排列；`t_M` 表示未保留组分的死时间，`t_R` 表示从进样到峰最大值的总保留时间；柱内推进方向从 `INJECT` 指向 `DETECT`；`u` 为流动相线速度，`v_i` 为组分带平均推进速度。
- **量纲/类型检查**：`V_M/F` 的量纲为时间；`k`、`p`、`N` 和 `R_s` 均无量纲；`t_R/σ` 与 `t_R/w_b` 为同单位时间之比；高斯指数为无量纲；实现输入均先限制为有限数值范围。
- **依据引用**：保留因子、死时间、总保留时间、迟滞因子、塔板数和峰分离度的定义分别依据 [R1]、[R2]、[R3]、[R4]、[R5]、[R6]；对称高斯峰仅作为教学近似，其适用边界参考 [R5] 与 [R7]。

#### 3. 核心关系与符号约定

$$
\phi_i=\sum_{j=1}^{i}q_j,\qquad
\boldsymbol p_i=\boldsymbol p_{i-1}+L_i
\begin{bmatrix}\cos\phi_i\\ \sin\phi_i\end{bmatrix},\qquad
e=\lVert\boldsymbol p_3-\boldsymbol t\rVert_2
$$

$$
\Delta q_i=\operatorname{atan2}\!\left(
(\boldsymbol p_3-\boldsymbol p_i)\times(\boldsymbol t-\boldsymbol p_i),
(\boldsymbol p_3-\boldsymbol p_i)\cdot(\boldsymbol t-\boldsymbol p_i)
\right),\qquad
q_i\leftarrow\operatorname{clip}\!\left(\operatorname{wrap}(q_i+\Delta q_i),-q_{\max},q_{\max}\right)
$$

$$
q_{\max}=\left(40+1.3p\right)\frac{\pi}{180},\qquad
R_{\max}=\sum_{i=1}^{3}L_i=2.44
$$

- **符号约定**：基座固定在原点，模型 `x` 轴向右、`y` 轴向上；`q_i` 为相对角，正值表示数学意义上的逆时针旋转；二维叉积取标量 `a_xb_y-a_yb_x`。每轮按 `i=3→1` 更新，单次修正限制在 `±π/3` 后再执行关节限位。
- **量纲/类型检查**：`sin`、`cos` 与 `atan2` 的输入为无量纲角度；`L_i`、`p_i`、`t` 和残差 `e` 都使用同一模型长度比例，向量相减与欧氏距离类型一致。
- **依据引用**：串联机构的正运动学、工作空间与逆运动学定义依据 [R1]；逐坐标优化与边界约束依据 [R2]；CCD 的末端到基座更新、角度限位与迭代局限依据 [R3]。

| 目标—末端虚线 | 残差向量与 `e` | 仅在残差大于容差时连接两点；颜色区分受限与越界 | 不表示规划路径、碰撞路径或控制输入 |
| 虚线可达圆 | `R_max=2.44` | 以基座为圆心、总臂长为半径 | 只给出无关节限位的必要几何外界，不等于完整受限工作空间 |

#### 8. 误差预算

| 来源 | 类型 | 估计范围 | 可见影响 | 处理方式 |
| --- | --- | --- | --- | --- |
| CCD 停止容差 | 算法近似 | 成功状态允许 `e≤0.008` 模型长度 | 目标环与末端可能存在极小间距 | 明示末端误差，不把成功读数强制改写为零 |
| 最大迭代数 | 截断误差 | 最多 28 轮，未收敛残差不限 | 受限或局部停滞时末端保留在当前姿态 | 用“受限”而非“不可达”描述几何圆内的未收敛结果 |
| 浮点运算 | 数值舍入 | 双精度下通常远小于 `1e-12`，但累计顺序固定 | 末位可能随运行环境产生极小差异 | 验证容差高于浮点噪声并固定关节遍历顺序 |
| 文本显示舍入 | 显示舍入 | 残差最多约 `±0.00005`，角度最多约 `±0.05°` | 读数末位与内部值不同 | 数值样例引用内部快照，界面只作可读显示 |
| Canvas 像素映射 | 素材尺度 | 小于约 `0.5 CSS px` | 目标环与末端视觉位置存在亚像素差 | 判定只使用模型坐标，不从截图反推结果 |

### 11.2 编码规范

- 每个实验封装为独立对象（如 `Calculus`、`ChemReaction`）
- 初始化函数命名：`initXxx()`，全局暴露
- Canvas 使用 `requestAnimationFrame` + `performance.now()` dt 驱动
- 响应式：`ResizeObserver` 监听容器尺寸（而非 window.resize）
- DPR 适配：`canvas.width = rect.width * dpr` + `ctx.setTransform(dpr, ...)`
- 交互：绑定 `mousemove`/`click`/`touchstart` 事件
- 教育面板：通过 `_injectXxxPanel()` 动态注入 DOM
- ARIA：Canvas 添加 `role="img"` + `aria-label`，按钮添加 `role`/`tabindex`/`aria-pressed`
- 清理：提供 `destroy()` 方法取消 rAF 和事件监听

- 学科主题色：`--accent-blue`(数学)、`--accent-purple`(物理)、`--accent-green`(化学)、`--accent-orange`(算法)、`--accent-teal`(生物)

- 字体大小：`--text-xs` 到 `--text-3xl`
- 圆角：`--radius-sm`/`--radius-md`/`--radius-lg`
