# 当前运行素材

镜湖开篇使用三张位图：无星点的大气背景、孩子原画和透明品牌标志。孩子原画的部件保持中性站姿，不随时间运动；星点、星群轨迹、极光、星火与湖面由独立三维对象和材质生成。

登录页的独立纹理和实际生成提示词见 [登录素材说明](../public/assets/login/ASSETS.md)；观星页的固定海岸图层、银河尘带和四张课程星云见 [观星素材说明](../public/assets/observatory/ASSETS.md)。前景位置和接触注册点以 [图层定义](../src/observatory/layers.js) 为准，课程星系以 [课程数据](../src/observatory/courses.js) 为准。三个页面共用 `brand.png`，原始参考图保留在上级 `plan1` 目录。

## atmosphere.png

位置：`public/assets/atmosphere.png`。

生成方式：内置 image_gen。依据用户确认的镜湖备选图，保留云雾、远山和地平线配色，移除固定星点、人物与特效。原始备选图保留在上级 plan1 目录。

实际提示词：

将附图制作成实时三维场景用的“纯大气与远山”背景底图。保持原图宽高比、色调、地平线位置（约71%高度）、低矮远山轮廓、蓝黑天空、粉色/淡金黄/柔紫地平线以及静谧辽阔的气氛。关键要求：彻底移除天空和湖中所有点状星星、亮点、星芒、流星、星迹线、星系、条纹光效；尤其不能再留下密密麻麻的固定星点，这些将全部由程序生成。天空上方应是清澈的深海军蓝，只有非常轻柔、弥散、低对比的蓝紫气体薄雾，不能保留明亮银河形状；从左下天际至右上可以有极浅的星尘雾气色带，但无任何点状颗粒。底部湖面也应平静、柔和，只反射远方天光和薄云，没有任何星点或发光轨迹，没有人物或文字，没有硬边道路和工业物体。地平线一带的粉金紫柔光保持原图美感与层次，亮度适中，不要白色过曝太阳圆盘。输出干净的摄影级/电影概念美术背景底图，无前景人物、无Logo、无星星、无极光、无额外文字。

## brand.png

位置：`public/assets/brand.png`。

生成方式：内置 image_gen，从已确认镜湖图提取星序签名字标及 Astra 副标题，透明背景。作为独立 HTML 品牌层使用，不参与湖面倒影。

## child.png

位置：`public/assets/child.png`。

生成方式：内置 image_gen，依据已确认镜湖图的孩子造型制作。当前运行使用这张原画的独立裁片，轮廓与关节注册由 `src/character-art.js` 定义；不使用几何体拼接的人物外形。

原画提示词：

从参考图提取并精细重绘中央那个小孩，做成网页步行动画可用的单个人物透明PNG素材。画面只有一个孩子，全身背面，约7–9岁，短微卷蓬松头发，深黑蓝连帽卫衣、黑色短裤、深色短袜与运动鞋，偏大的儿童头身比、窄肩，保持原图同一个孩子的穿着与背影造型，深黑剪影但有微妙衣褶，头顶和右肩有很细暖金色逆光。人物面向正前方背对镜头，双腿自然分开约髋宽，脚都朝前、双脚落在同一水平基线上，双臂自然垂下且稍微离开躯干；中性站姿，便于后续分部位骨骼动画。不要人物前面、不要侧面、不要成人、不要书包，不要另一人物。紧凑居中构图，人物占画面高度85%，竖幅2:3。背景是真正全透明alpha，绝不要棋盘格、不带湖水、不带地面、不带脚底影子、不带倒影、不带文字。仅一个高质量完整儿童背影精灵。
