# 实验副本与观星页接入

源目录为 `D:/代码玩具测试/工科实验室`。此次复制保留原活动身份和数值／渲染实现，来源提交、复制时间与数量以 [`public/labs/import-manifest.json`](../public/labs/import-manifest.json) 为准。原项目没有被修改。

## 内容与跳转

- 工科实验室：数学、物理、化学、算法、生物，90 项。
- 代码空间：6 个方向，18 项。
- 未来星系：6 个方向，19 项。机械臂仍归未来星系工程方向。
- AI 智境没有同名源空间，本轮保留原来的预览，不重复登记数据科学活动。

星图和望远镜目录共用 [`src/data/lab-catalog.json`](../src/data/lab-catalog.json)。它由源项目的活动目录、实验配置与课程 manifest 导出，页面不另写一套实验名称和链接。`courses.js` 只保留星系布局、风格以及 AI 预览。

从观星页进入 `experiment.html?activity=physics.double-pendulum-chaos`，工作区根据稳定身份解析到 `labs/index.html#physics/double-pendulum-chaos`。实验始终从当前项目副本运行，并占满窗口，沿用原页面的学科导航、实验切换与搜索，不再叠加外层顶栏和目录。原页面内部路由变化通过 `public/labs-host/bridge.js` 通知工作区更新浏览器标题。

原页面的“星序／返回星序总览”入口统一返回当前观星主页面；工科导航也沿用同款“星序”入口。进入实验前将当前相机、星系和学科保存到本标签页历史条目的状态中；未发生实验内部导航时，返回可恢复原星图。直接打开工作区或在实验内切换页面后，返回使用 `observatory.html#galaxy=engineering&subject=physics` 定位到学科，避免被子页面历史记录留在实验内。修饰键或中键打开星序链接、直接打开实验副本也使用当前观星主页面。没有保存账号、密码或学习成绩。

## 复制范围

`public/labs/` 包含原 `pages/`、`shared/`、`codevis/`、`UI/` 的公开运行文件和第三方许可证。角色管理页、服务端、数据库、依赖安装目录及测试产物未复制。

两个运行 HTML 采用源项目已有公开资源打包方式：加入公开探索标记和样式，移除账号启动脚本，并加入本项目的展示路由桥接。普通实验脚本、公式与求解器保留原件。原项目后端接口、课程发布与记录逻辑没有改动；自主探索不会生成正式课程完成结果。代码活动可运行公开样例，正式提交继续要求原系统账号和课程上下文。

## 导入与维护

在一个尚未导入的项目副本中，可用 Node 24.20.0 或更新版本执行：

```powershell
node scripts/import-labs.mjs 'D:/代码玩具测试/工科实验室'
```

导入器遇到已有 `public/labs/` 或目录快照会拒绝覆盖，以保护后续本地修改。重新同步需要先比较原项目变化与本地副本，明确合并范围后再处理，不能直接重新复制覆盖。

构建和运行只需要当前目录，不再读取源目录。源项目后续更新不会自动改变这份副本。
