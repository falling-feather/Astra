# 星序 Astra

包含镜湖开篇、登录页、悬崖观星主页面和本地实验工作区。以已确认参考图为视觉依据，使用独立原画素材、Three.js / WebGL 场景和原生网页控件实现；三个学习空间已接入工科实验室源码中的 127 项实验与活动副本。

## 打开网页

在本目录运行：

```sh
pnpm install
pnpm dev
```

访问 http://127.0.0.1:5173/ 。也可以在 Windows 中双击 `启动星序.cmd`。

构建独立静态文件：

```sh
pnpm build
pnpm preview
```

生产预览地址为 http://127.0.0.1:4173/ 。`dist/` 可以交给静态网站服务器托管。网页需要 HTTP 服务，不能直接双击 HTML 通过 `file://` 打开。

## 页面与登录演示

| 页面 | 本地路径 | 入口 |
| --- | --- | --- |
| 镜湖开篇 | `/index.html` 或 `/` | 点击画面「点击以进入」或按 Enter 进入账号登录页 |
| 登录 | `/login.html` | 填写账号与密码后进入观星页 |
| 悬崖观星 | `/observatory.html` | 左上星按钮展开北斗七星菜单 |
| 实验工作区 | `/experiment.html?activity=活动身份` | 星图或目录中的「进入实验」 |

登录目前是用户确认的**本地交互演示**，没有服务端账号系统。任意非空账号和密码均可体验；注册与忘记密码入口说明演示方式，并可填入演示资料。`src/shared/session.js` 是登录状态的唯一来源：

- `sessionStorage` 只保存本标签页的显示名和 `demo` 标记，刷新后仍可显示欢迎文字；不保存密码。
- 「记住我」只在 `localStorage` 中保存用于预填的账号。取消勾选后登录会清除此前记住的账号。
- 退出会清除演示会话；直接打开观星页仍可作为访客预览。
- 邮箱账号以 `@` 前的名称显示欢迎文字。账号不是身份凭据，此演示不能用于保护真实用户数据。

`vite.config.js` 将四个 HTML 页面分别作为正式构建入口；页面互链在开发与生产预览中使用同一路径。原实验的本地副本随 `public/labs/` 打包，运行不依赖原目录。

## 登录页与观星页操作

观星桌面端已按 [2026-10-22 视觉概念稿](docs/concepts-2026-10-22/observatory-desktop-concept.png) 调整：宽度达到 900px 时，海面占约三成，人物、望远镜和悬崖收在右下；星云下展示真实学科／实验数量和切角课程按钮，底部采用统一导航带。桌面构图与点击范围由 `desktop-composition.js`、`coastal-layout.js` 共同推导，调整窗口不累积缩放。窄屏沿用原布局。镜湖开篇按用户选定的游戏式入口衔接账号登录，详见下方操作说明。

- 登录页左侧为三维星系仪：玻璃星核、细刻度金属环、水晶节点和轨道卫星分别渲染；星核按实际视线遮住后方星环和节点，前方器械仍正常显示。深蓝灰蒙版降低背景对比。右侧表单采用分段双框与非对称大切角。指针带来轻微视差，左下可暂停。
- 观星画面保留海潮、天际、右下悬崖、孩子和望远镜。拖动只改变上方星空的相机，前景位置固定，孩子眼睛与目镜、双脚与岩面保持对齐。原银河尘带和四张独立课程星云位于可拖动的星空层。
- 上方星空可以自由拖动、惯性滑行、滚轮或双指缩放；横向首尾环绕。工科实验室、代码空间、未来星系、AI智境分别有独立造型、光色、星点和光丝。底部星系定位按钮与望远镜课程目录提供快捷入口；自动定位沿环形世界的短路径移动。
- 星云采用较小的远景尺度与柔和反差；光丝以断续的流动亮段出现。当前星云的色光同步投向薄云、海面和前景亮部，海上反光随波浪破碎，并在星云移出视野时淡去。
- 四个学科名称、当前星系标记、课程目录及视图控制保持可见。星云下方常驻名称和「查看课程」，普通点击即可打开对应课程；拖动用于探索天空。⭐ 和品牌始终保留，望远镜的补充标签在悬停或键盘聚焦时出现。
- 左上星按钮展开七条长短不等、末端渐隐的光带；七个末端组成北斗。展开时黑灰蒙版压暗整个背景，突出光带、连线和星位。方向键上下移动焦点，Home / End 跳到首尾，Esc 或点击外侧收起。
- 望远镜打开全部目录，可搜索星系、学科与具体实验名；搜索结果可直接进入实验。点击具名星云的「查看课程」会展开学科星图：工科实验室 5 个学科共 90 项、代码空间 6 个方向共 18 项、未来星系 6 个方向共 19 项。AI 智境继续保留 3 个预览方向，不混入已导入的实验计数。
- 选中学科后显示实验名称、介绍、筛选和「进入实验」链接；「专注浏览目录」提供原生阅读面板。实验以同一站点的全屏工作区打开，沿用原页面导航、实验切换和搜索；原有「星序」入口返回当前观星主页面。浏览器返回会保留先前的星图状态，刷新或直接进入返回地址也可恢复学科目录。
- 星图的「返回观星」会把节点和云层收回，并恢复打开前的相机位置。展开途中也能返回；暂停环境时展开／收回仍可操作，减少动态效果时立即切换状态。实验采用源项目已有的公开探索模式，正式账号、成绩、提交和业务记录仍由原项目负责，本轮未接入这些后端流程。
- 北斗保留星图总览、星际探索、观测日志、知识星库、创作工坊、灵感收藏、个人中心七项。「创作工坊」调整星光与光丝强度；日志可保存、回看和删除，原有三个观测星域的收藏和记录继续沿用原存储结构；个人中心可退出演示。
- 观星页右下可暂停，空格也可控制播放；表单、按钮和弹窗中的键盘操作保留原生行为。隐藏标签页停止动画，返回时不补播离开期间的时间。
- 海洋由独立细分网格产生更明显的中景起伏，破碎浪峰向前推进，短暂的浪花从浪尖上扬。天空约每三秒出现一颗流星，亮头、渐细尾迹与偶尔成组的流星独立运行。

所有菜单内容都是这次演示中的可用交互；真实账号同步和服务端存储不在本轮实现范围。

观星素材的基准位置、尺寸、调色和眼睛／目镜／落脚注册点定义在 [`src/observatory/layers.js`](src/observatory/layers.js)，桌面变换由 [`desktop-composition.js`](src/observatory/desktop-composition.js) 计算，天空交界和望远镜点击区域由 [`coastal-layout.js`](src/observatory/coastal-layout.js) 读取同一变换推导。星系布局以 [`courses.js`](src/observatory/courses.js) 为准；实验目录从已复制的源项目权威注册表导出，导入方式和职责见 [实验接入说明](docs/labs.md)。素材与实际生成提示词见 [观星素材说明](public/assets/observatory/ASSETS.md)。

## 鼠标星光尾迹

镜湖、登录和观星页面共用 [`src/shared/star-trail.js`](src/shared/star-trail.js)。鼠标移动产生冰蓝、淡金和浅紫的细星光，沿轨迹逐渐消散；停下后自动停止绘制。尾迹不拦截点击，也不替换鼠标指针。暂停场景、离开页面或开启「减少动态效果」会清除尾迹；触屏拖动不发射粒子。路径采样、粒子数量与寿命统一在 [`star-trail-particles.js`](src/shared/star-trail-particles.js) 中定义。

## 镜湖画面与操作

- 开篇采用安静的游戏式入口：Logo 与登录页共享尺度，中央只有轻微呼吸的「点击以进入」及小字「账号登录」。画面区域为通往 `login.html` 的原生链接，点击、Tab 后 Enter、Ctrl／中键打开链接均保留浏览器行为；在空白区域按 Enter 也可进入。无需等待背景加载或播放完成。
- 景观选择收进左下角「景观」菜单，Esc 收起并归还焦点；暂停和全屏位于右下角。这些控件独立于进入链接，不会误触登录。镜湖色彩与星火连续线收敛，人物静止与两脚涟漪继续保留。
- 开篇与登录页采用一致的 Logo 尺度和短暂的入场淡入；跳转始终由原生链接直接完成，背景加载不会阻挡进入。减少动态效果时关闭淡入，不添加跳转计时器。

- 三种动态层依次轮播：镜湖星群 → 条纹星火 → 垂落极光；每种停留 18 秒，以 7 秒柔和过渡。
- 展开左下景观菜单后，点击场景名称可以手动切换。过渡途中再次选择时，从当前混合画面继续，不闪回。
- 人物沿用孩子原画，保持双脚着地的静止站姿；不再抬脚、摆臂、摇晃或向前移动，镜头也固定。原画部件与注册点见 `src/character-art.js`。
- 仅从两个固定脚位周期性产生轻微涟漪，扩散后渐渐消失。涟漪独立于人物动作，保持播放时持续运行。湖面每帧反射人物、星群、流星和光幕。
- 星点是独立粒子，分别闪烁；归位星群从分散起点沿曲线跨越天空，汇入各自目标星位，停留后进入下一轮。流星有移动头部和渐淡尾迹。
- 极光由多层动态网格构成：不同高度与不同列沿各自风场变形，光幕内的细丝亮度持续流动。条纹星火具有独立光丝、柔光带与沿线飞行的亮点。
- 右下角可以暂停或进入全屏。空格暂停/继续，左右方向键切换场景，`F` 切换全屏；按钮、链接和景观菜单获得焦点时保留其原生键盘操作。
- 暂停时天空动效和脚边水纹一并冻结。
- 自动遵守系统「减少动态效果」偏好；仍可手动开始播放。后台标签页暂停计时，返回时不快进。

| `src/observatory/coastal-layout.js` | 固定前景、天空视口与望远镜点击区域 |
| `src/observatory/desktop-composition.js` | 桌面海岸比例、人物成组缩放与课程标题布局 |

所有运行时图片与依赖均由本站提供，不调用外部内容 API。需要支持 WebGL 2 的现代浏览器。镜湖渲染上限为 60 FPS，登录星系仪上限为 30 FPS；观星海岸限制绘制像素总量并跟随浏览器帧循环。三个场景均限制高像素密度屏幕的绘制分辨率。较旧设备的帧率会取决于显卡与浏览器。

## 验证

```sh
pnpm test
pnpm build
```

测试覆盖轮播闭环、连续权重、暂停/后台恢复、人物与镜湖相机保持静止、固定脚位的涟漪、星群迁移、极光非刚性形变，以及演示登录、实验检索、本地入口完整性、实验身份唯一性、五至六分支布局、星空环绕和缩放、海岸位置固定、环境光连续混合与资源释放。浏览器验证使用外部 Edge，检查实验进入、参数操作、目录切换、返回、响应式布局和控制台。目录链接检查不等于对所有实验科学内容逐一验收。
